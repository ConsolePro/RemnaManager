# RemnaManager v1.2.1

- Основная команда установки запускает `install.sh` из репозитория. Скрипт сам выбирает актуальный стабильный релиз и готовый бинарник для ОС и архитектуры сервера, проверяя SHA256. Компиляция на сервере не требуется.
- В шапке TUI отображаются название ОС, версия дистрибутива и архитектура. Информация сохраняется и в компактном режиме терминала.
- Переработан README: назначение приложения, доступные возможности, требования, установка, управление и ссылки на документацию.
- Добавлены векторный логотип и снимок действительно запущенного TUI в отдельном Linux-контейнере.

```bash
curl -fsSL https://raw.githubusercontent.com/ConsolePro/RemnaManager/main/install.sh | sudo bash
```

Запуск: `sudo re` или `sudo remanager`.
