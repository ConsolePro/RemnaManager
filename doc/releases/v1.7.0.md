# RemnaManager v1.7.0

- Мастер установки сначала выбирает размещение панели и подписки, затем собирает домены и SSH, предлагает прокси, SSL для Nginx и защиту панели. Перед установкой выполняется асинхронная предварительная проверка и показывается сводка без секретов.
- Для отдельного сервера подписки добавлен SSH по паролю с обязательным подтверждением ключа сервера. Пароль хранится в зашифрованном состоянии и не передаётся через командную строку.
- Nginx поддерживает acme.sh, Wildcard через Cloudflare/Gcore/Bunny.net и импорт сертификата. Для одного сервера используется общий SAN-сертификат, для двух — независимые сертификаты и продление. DNS-токены продления шифруются; импорт собственного PEM отключает прежнее ACME-продление.
- Официальные Compose и env-шаблоны backend 3.4.9 загружаются с проверкой SHA-256. Подмена недоступных артефактов сгенерированными файлами запрещена.
- Добавлены изменение доменов и настройка сертификатов после установки с резервной копией, журналом восстановления и откатом. Размещение между одним и двумя серверами автоматически не мигрирует.
- Сохранены Cookie, TinyAuth и MFA. Итоговые инструкции показывают соответствующий способ входа и начальные учётные данные. TinyAuth использует отдельный поддомен панели.
- Добавлены проверки 36 комбинаций интерфейса, конфигураций и команд, локальные SSH-тесты и изолированные Linux-проверки DNS-01, cron, шифрования и восстановления.

Проверки: `go test ./...`, `go vet ./...`, сборка, форматирование и Linux-тесты установщика. Реальные DNS API, публичный выпуск сертификатов, два внешних сервера и регистрация MFA требуют проверки на тестовой инфраструктуре. Изменение доменов/SSL для старых форматов установки требует отдельной миграции.

Подробности: [мастер установки](../installer-wizard.md).
