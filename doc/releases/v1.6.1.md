# RemnaManager v1.6.1

- Исправлена проверка портов при установке Nginx по новым YAML-шаблонам: занятый TCP 80 больше не блокирует установку. Эта схема использует публичный TCP 443 и локальный ACME 8443.
- Проверка учитывает реальные порты панели, PostgreSQL, метрик и локальной подписки. При удалённой подписке локальный 3010 не резервируется.
- Системные конфигурации Nginx/Caddy больше не блокируют установку отдельного Docker-прокси сами по себе. Проверка занятых необходимых портов сохраняется; существующие службы не останавливаются.
- Аналогичная проверка исправлена для удалённого сервера подписки. Для Caddy и старой схемы Nginx с HTTP-01 порт 80 по-прежнему требуется.
- Уточнены подсказки мастера и добавлены проверки сценариев с занятыми портами 80, 443 и 8443.
