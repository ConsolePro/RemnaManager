# RemnaManager v1.6.3

- Исправлен выбор проверки доменов в новой схеме Nginx: удалён конфликтующий `--standalone`, который включал HTTP-01 на порту 80 для первого домена. `--alpn` самостоятельно включает standalone TLS-ALPN для всех доменов общего сертификата.
- Сохранены локальный порт 8443 и перенаправление проверки с публичного 443. Занятый порт 80 не используется этой схемой.
- Добавлена регрессионная проверка отсутствия HTTP-01 и возможность проверить параметры настоящим парсером acme.sh без обращения к центру сертификации.
- Обновите менеджер и повторите установку с прежними параметрами. Удалять данные или останавливать системный Nginx на порту 80 не требуется.
