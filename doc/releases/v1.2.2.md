# RemnaManager v1.2.2

- При установке ноды используется Xray из официального образа Remnawave Node; отдельное обновление ядра не запускается.
- Перед обновлением Xray текущая версия из панели сравнивается с последним стабильным релизом XTLS/Xray-core. Если версия актуальная или выше, архив не скачивается и нода не перезапускается.
- Добавлен отдельный пункт «Откатить ядро Xray»: выбор более ранней стабильной версии из официальных GitHub Releases, подтверждение и установка с проверкой SHA256.
- Сравнение версий повторяется перед выполнением. Неизвестная текущая версия блокирует замену ядра.
- Обновление и ручной откат сохраняют образ ноды и настройки; при ошибке возвращается прежнее ядро.
