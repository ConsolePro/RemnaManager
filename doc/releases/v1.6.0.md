# RemnaManager v1.6.0

- Новые установки используют готовые YAML-шаблоны Remnawave, официальные имена сервисов и сеть remnawave-network. Compose-файлы панели, подписки и прокси размещаются отдельно в /opt/remnawave.
- При изменении образа правится только image; пользовательские настройки Compose и .env сохраняются.
- Добавлена установка и управление отдельной страницей подписки через SSH с подтверждением fingerprint.
- Для Nginx при совместном размещении используется общий SAN-сертификат. Проверяются регистрация ACME-аккаунта и ACCOUNT_URL; при ошибке ZeroSSL выполняется переход на Let's Encrypt. TLS-ALPN использует временную передачу публичного 443 на локальный 8443.
- Добавлены резервные копии с проверкой целостности, восстановление, шифрование секретов состояния, смена прокси с восстановлением после ошибки и диагностика WASM.
- Существующие установки сохраняют прежние имена проектов и томов; автоматического преобразования формата нет.

Проверены Go-тесты и vet, Linux-тесты установщика, Docker Compose-схема, Nginx/Caddy с Cookie/TinyAuth/MFA и сценарии ACME с подменой внешних команд. Реальный выпуск сертификатов на публичных доменах и браузерная задержка WASM на пользовательском сервере не проверялись.

Подробности: [управление панелью](../panel-management.md).
