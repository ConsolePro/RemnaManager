# RemnaManager v1.6.5

- Исправлен тайм-аут HTTPS после применения firewall: входящие подключения к опубликованным HTTP/HTTPS-портам Docker разрешены в цепочке forward. Другие опубликованные порты остаются закрыты. Для Caddy разрешён также опубликованный UDP 443.
- Итоговый экран установки и проверки SSH показывает полную ссылку входа с Cookie-параметром; для MFA используется адрес портала `/r`.
- Для существующих установок добавлен пункт «Панель и компоненты → Восстановить HTTPS в firewall». Исправление применяется к таблице RemnaManager и сохраняется после перезагрузки; порты SSH сохраняются. При ошибке возвращается предыдущая политика.
- Защищённая ссылка также доступна в разделе «Доступ к панели». Не требуется повторно устанавливать панель или выпускать сертификаты.
