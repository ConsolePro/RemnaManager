# RemnaManager v1.6.4

- Исправлена проверка продления сертификатов: распознаётся стандартная запись acme.sh с кавычками вокруг домашнего каталога. Успешный выпуск больше не завершается ложной ошибкой `ACME renewal cron is missing`.
- Общая проверка cron применяется к новой и прежней схемам установки и при повторном запуске с уже действующим сертификатом. Повторный выпуск для исправления cron не требуется.
- Проверяется задание именно текущего клиента; комментарии и задания другого экземпляра не считаются настроенным продлением. Чужие задания не изменяются.
- Добавлены Linux-проверки форматов cron, установки отсутствующего задания, повторного запуска и ошибок чтения и установки. Предусмотрен запуск тестов с настоящим acme.sh.
