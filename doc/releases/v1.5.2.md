# RemnaManager v1.5.2

- Исправлена проверка Xray при установке и удалении WARP. Remna Node запускает ядро через rw-core; прежний поиск только по имени xray мог не обнаружить работающий процесс и оставлял удаление незавершённым.
- Проверка теперь использует реальный исполняемый файл через /proc, PID, время запуска и идентификатор контейнера. Поддерживаются rw-core, обычный xray и управляемый панелью путь ядра.
- Установка WARP после прерванного удаления автоматически завершает очистку и затем выполняет новую установку. Ручное изменение журналов не требуется.
- При удалении после неудачной установки, которая не меняла профиль, лишний перезапуск Xray не запрашивается. Завершённая очистка фиксируется до дополнительной проверки здоровья, поэтому её сбой не оставляет компонент в статусе «удаляется».
- Продолжение удаления использует уже подтверждённый перезапуск. Старый маркер missing не принимается как доказательство перезапуска. Перед изменением профиля при удалении выполняется предварительная проверка конфигурации Xray.
- Проверены сценарии зависшего удаления, повторной установки, отказа проверки после очистки и удаления после неудачной установки. Обнаружение процессов проверено на реальных процессах, включая официальный Xray v26.11.9 под именами xray и rw-core.

После обновления повторите «Удалить WARP Native с ноды». Если нужна новая установка, её можно выбрать сразу: прерванное удаление завершится автоматически. Аккаунт и резервные копии сохраняются.
