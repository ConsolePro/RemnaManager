# RemnaManager v1.3.2

- Версии Xray ниже `v26.6.1` исключены из отката и блокируются до скачивания: они не поддерживают передачу конфигурации через `@rwint`, которую использует актуальная Remna Node.
- До замены выбранное ядро проверяет текущую JSON-конфигурацию в контейнере через `run -test`. При несовместимости работающее ядро продолжает работать, Compose не изменяется.
- После автоматического возврата проверяются прежнее ядро, SHA256 работающего процесса и версия в панели. Незавершённое восстановление больше не считается успешным только по наличию связи с нодой.
- Сообщения Xray, таймаута проверки и восстановления переведены для русского интерфейса; английские технические причины сохраняются в цепочке ошибок для диагностики.
- Несовместимость `v25.12.8` и предварительная проверка воспроизведены на официальных бинарниках Xray в отдельном Linux-контейнере. Токен внутреннего сокета не выводится.
