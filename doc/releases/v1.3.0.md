# RemnaManager v1.3.0

- Исправлено получение версии Xray из актуального API Remnawave: поддерживаются `versions.xray` / `versions.node` и прежние `xrayVersion` / `nodeVersion`. Проверка после установки ядра также использует актуальный формат.
- «Ноды и расширения» сразу открывает список нод. После выбора показывается карточка с именем, адресом, статусом, версиями Xray и Remna Node, аптаймом Xray и сервера из панели, затем действиями для выбранной ноды.
- Обновление и откат объединены в «Ядро Xray»: при устаревшем ядре предлагается новый стабильный релиз, при актуальном — список более ранних стабильных версий из XTLS/Xray-core.
- Убран отдельный пункт статуса. Добавление ноды и незавершённые установки доступны внизу списка; возврат из операций ведёт к выбранной ноде.
- Добавлено удаление ноды из панели с подтверждением. Удалённый контейнер, профили, хосты и сквады сохраняются; это явно указано перед удалением.
- Исправлена прокрутка выбранного действия и версии в компактных терминалах.
